📋 Задача для нового чата


Привет! Продолжаем работу над CrABook (создание аудиокниг с TTS Silero).

📁 Структура проекта:
crabook/
├── crabook.py              # Оркестратор
├── core/                   # Ядро (config_manager, context, pipeline)
├── services/               # Бизнес-логика
├── engines/                # Движки (TTS, акценты, SSML, аудио)
├── models/                 # Dataclass'ы
├── utils/                  # Утилиты
├── config/                 # Глобальные JSON конфиги
├── book_specific/          # Конфиги для конкретных книг
├── book/                   # Входные файлы
└── audio/                  # Выходные аудио

🎯 ЗАДАЧА:
Проанализировать текст книги и дополнить конфигурационные файлы.

📎 Я пришлю:
1. [file name]: book/название_книги.txt — полный текст книги
2. [file name]: config/accent_overrides.json — текущий словарь ударений
3. [file name]: config/emotions.json — текущие эмоции
4. [file name]: config/keywords_effects.json — текущие эффекты

📝 ЧТО НУЖНО:
1. Найти в тексте слова, требующие правильной расстановки ударений (омографы, редкие слова, имена собственные)
2. Выделить эмоционально окрашенные слова и фразы, характерные для этой книги
3. Найти повторяющиеся речевые обороты, диалоговые маркеры
4. Обнаружить специфические термины, имена, аббревиатуры

✅ ВЫХОД:
- Дополненный accent_overrides.json (новые позиции)
- Дополненный emotions.json (новые ключевые слова)
- Дополненный keywords_effects.json (новые эффекты)
- book_specific/название_книги.json (специфичные для книги настройки)

⚠️ ВАЖНО:
- Сохранить существующие позиции в конфигах
- Только ДОБАВИТЬ новые, не удалять старые
- Для имён собственных и терминов использовать формат: "слово": "уд+арение"
- Выдать готовые JSON файлы для замены
- структура файлов должна быть неизменной, не переварачивай массивы и не добавляй вложения
