📚 Туториал
Шаг 1: Подготовка книги

Поместите файл книги в папку book/. Например, book/war_and_peace.txt.
Шаг 2: Базовый запуск
bash

python crabook.py

CrABook найдёт файл, обработает его и создаст audio/war_and_peace.m4a.
Шаг 3: Настройка под книгу

Создайте файл book_specific/war_and_peace.json:
json

{
  "accents": {
    "Болконский": "Болк+онский",
    "Безухов": "Без+ухов"
  },
  "custom_effects": {
    "война": "loud",
    "любовь": "soft"
  }
}

Шаг 4: Выбор голоса и жанра
bash

python crabook.py -v eugene -g drama

Шаг 5: Оптимизация для длинной книги
bash

python crabook.py -c 1200 -w 8 --format mp3 --bitrate 96k

    -c 1200 — увеличиваем размер чанка

    -w 8 — больше потоков для ускорения

    --format mp3 — меньший размер файла

Шаг 6: Отладка при проблемах
bash

python crabook.py --debug VERBOSE

Логи сохранятся в logs/debug_*.log, а промежуточные файлы — в logs/debug_chunk_*.txt.
Шаг 7: Тонкая настройка аудио

Если звук кажется резким:
bash

python crabook.py --deesser-threshold -35

Если есть фоновый шум:
bash

python crabook.py --spectral-nr-amount 0.2

Если звук слишком громкий/тихий:
bash

python crabook.py --target-volume -20

🔧 Решение проблем
❌ "Модуль не найден"

CrABook автоматически устанавливает зависимости. Если ошибка сохраняется:
bash

pip install -r requirements.txt

❌ "FFmpeg не найден"

Установите FFmpeg (см. Установка).
❌ "Empty prosody tag"

Включите автоисправление SSML:
bash

python crabook.py --debug INFO

❌ "Дребезг в аудио"

Проверьте настройки нормализации:
bash

python crabook.py --target-volume -23 --no-deesser --no-spectral-nr

❌ "Слишком медленно"

    Увеличьте количество потоков: -w 8

    Увеличьте размер чанка: -c 1500

    Используйте GPU: установите CUDA-совместимый PyTorch

❌ "Ошибка валидации SSML"

Проверьте логи в logs/ и файлы чанков в logs/debug_chunk_*.txt.
