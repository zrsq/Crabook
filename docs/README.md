# 🎙️ CrABook — Creator of Audio Books

**CrABook** — это мощный инструмент для автоматического создания аудиокниг из текстовых файлов с использованием нейросетевого синтеза речи (TTS) и интеллектуальной обработки текста.

## ✨ Возможности

### 🎯 Интеллектуальная обработка текста
- Автоматическая расстановка ударений с помощью нейросетевой модели **RUAccent**
- Очистка текста от мусора (номера страниц, артефакты форматирования)
- Расшифровка аббревиатур (т.е. → то есть, руб. → рублей)
- Преобразование чисел и дат в читаемую форму
- Синтаксический анализ предложений (Natasha / SpaCy)

### 🎭 SSML-разметка
- Автоматическая расстановка пауз после знаков препинания
- Разметка диалогов и прямой речи
- Эмоциональная окраска ключевых слов
- Замедление длинных и сложных слов
- Разметка глав с увеличенными паузами

### 🎙️ Синтез речи
- Использование **Silero TTS v5** — одной из лучших русскоязычных TTS моделей
- Поддержка голосов: `xenia`, `eugene`, `aidar`, `baya`, `kseniya`
- Параллельная генерация чанков для ускорения
- Умное разбиение текста без разрыва SSML-тегов

### 🎧 Профессиональная обработка аудио
- **De-esser** — удаление резких шипящих звуков
- **Spectral Noise Reduction** — подавление цифрового шума
- **Low-pass фильтр** — сглаживание высоких частот
- **Нормализация LUFS** — выравнивание громкости по стандарту EBU R128
- Конвертация в **AAC (M4A)**, **MP3**, **WAV**

### 🐛 Отладка и мониторинг
- Многоуровневая система логирования
- Сохранение промежуточных файлов в режиме отладки
- Валидация SSML с автоисправлением ошибок
- Статистика по каждому этапу обработки
